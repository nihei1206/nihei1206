## こんにちは、motaです

ホーチミン市を拠点に、生成AI領域のプロダクトマネジメントと個人開発をしています。
仕事や暮らしのなかで見つけた課題を、小さく作り、公開し、実際に運用しながら育てるのが好きです。

いまの主なテーマは **AI × Product / Japan × Vietnam / Writing & Community**。
企画だけで終わらせず、実装・公開・運用までつなげることを大切にしています。
